# Pixel Quest — Android (Capacitor)

The existing PIXEL QUEST web game, packaged as a native Android app.

| Setting | Value |
|---|---|
| App name | Pixel Quest |
| Application ID | `com.pixelquest.game` |
| Framework | Capacitor 7 (Android) |
| Orientation | Landscape (`sensorLandscape`) |
| Display | Immersive fullscreen: status and navigation bars hidden, notch area used |
| Offline | Yes. The whole game is one local file (`www/index.html`), and all art and audio are generated in code |
| Saves | Browser `localStorage` inside the app's WebView, which persists between launches |
| Back button | Pauses or resumes during play; exits from the title screen |
| Signing | Debug key in `keystore/debug.keystore`. It stays the same across builds, so new versions install over old ones |

## Build the APK without installing anything (GitHub Actions)

1. Upload this folder's contents to a new GitHub repository.
2. The **Build Android APK** workflow (`.github/workflows/build-apk.yml`) starts automatically.
3. After about 5–10 minutes, `PixelQuest.apk` appears on the repository's **Releases** page. The full generated Android Studio project (`PixelQuest-Android-Project.zip`) is published there too.

If the `.github` folder didn't upload (it's hidden on some computers), go to **Actions → "set up a workflow yourself"**, paste the contents of `github-workflow-copy/build-apk.yml`, and commit.

## Build locally (developers)

Requirements: Node 20+, JDK 21, Android SDK (API 35).

```bash
npm install
npm run android:setup      # bundle the game, create android/, apply customizations, sync
cp keystore/debug.keystore ~/.android/debug.keystore   # optional: stable signing key
npm run android:apk        # -> android/app/build/outputs/apk/debug/app-debug.apk
```

After changing the game (`game/src/*.js`), run `npm run android:sync` and then rebuild.

## Layout

```
game/                      original PIXEL QUEST source (unchanged gameplay; adds Android back-button and audio-resume hooks)
www/index.html             offline single-file game bundle (generated by `npm run build:web`)
capacitor.config.json      app id, name, web dir
native/MainActivity.java   immersive fullscreen activity
native/res/                launcher icons (adaptive + legacy), splash screens, colors
scripts/build-web.js       bundles the game into www/
scripts/customize-android.js  applies landscape, fullscreen, theme, icons to the generated android/ project
keystore/debug.keystore    debug signing key (alias androiddebugkey, password android). For testing only
assets/icon-512.png        512px icon (store listing / preview)
.github/workflows/build-apk.yml  cloud build
```

## Note
The `android/` native project is generated by Capacitor's official template (`npx cap add android`) during the build, and then customized by `scripts/customize-android.js`. This keeps the native project in sync with the installed Capacitor version.
